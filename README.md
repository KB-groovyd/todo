# TODO

依存ライブラリ・ビルド不要のシンプルな TODO アプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 機能

- TODO の追加（Enter または「追加」ボタン）
- 完了／未完了の切り替え、全件一括切り替え（入力欄左の ✓）
- ダブルクリックで編集（Enter で確定、Esc でキャンセル、空にすると削除）
- 削除（行にカーソルを合わせると × が表示されます）
- 表示の絞り込み：すべて／未完了／完了済み（URL ハッシュ `#/active` などで保持）
- 完了済みの一括削除
- `localStorage` への自動保存（別タブでの変更も反映）
- ダークモード対応（OS の設定に追従）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面のマークアップ |
| `style.css` | スタイル（ライト／ダーク） |
| `app.js` | 状態管理・描画・イベント処理 |
